# CPU Limiter

Универсальный Bash-скрипт для гибкого управления производительностью процессора в Linux. Позволяет ограничивать частоту, отключать ядра и Turbo Boost для экономии энергии и снижения температуры.

## 🚀 Основные возможности

- **Выбор частоты:** Установка конкретной максимальной частоты для всех ядер.
- **Управление ядрами:** Возможность оставить активным только нужное количество ядер (от 1 до макс).
- **Профили и ручное управление:** Быстрое включение эконом-режима или точная настройка параметров.
- **Автоматический бэкап:** Скрипт запоминает настройки системы перед первым изменением и возвращает их при выключении.
- **Инфо-панель:** Просмотр текущего состояния ядер, частот и режима работы.

## 📋 Требования

- Linux с интерфейсом `sysfs` (директория `/sys/devices/system/cpu`).
- Права `sudo`.

## 🛠 Установка

1. Сделайте файл исполняемым:
   ```bash
   chmod +x cpu-limiter.sh
   ```

## 📖 Использование

### 1. Просмотр доступных частот
Узнайте, какие частоты (в kHz) поддерживает ваш процессор:
```bash
./cpu-limiter.sh freqs
```

### 2. Включение лимитера (Режим "Эконом")
По умолчанию устанавливает минимальную частоту и оставляет только 1 активное ядро:
```bash
sudo ./cpu-limiter.sh on
```

### 3. Включение с конкретными параметрами
Вы можете указать желаемую частоту и количество ядер (например, 1.2 ГГц и 2 ядра):
```bash
sudo ./cpu-limiter.sh on 1200000 2
```

### 4. Ручное изменение отдельных параметров
Если лимитер уже включен или вы хотите изменить только один параметр:
- **Установить частоту:** `sudo ./cpu-limiter.sh set-freq 800000`
- **Установить кол-во ядер:** `sudo ./cpu-limiter.sh set-cores 4`

### 5. Проверка текущего статуса
Выводит детальную информацию о текущем состоянии процессора:
```bash
./cpu-limiter.sh status
```

### 6. Восстановление системы
Отключает все ограничения и возвращает систему к исходным настройкам:
```bash
sudo ./cpu-limiter.sh off
```

## 🔍 Как это работает

1. **Бэкап:** При первом запуске любой команды изменения создается папка `/tmp/cpu_limit_backup`.
2. **Частота:** Записывает выбранное значение в `scaling_max_freq` и переводит ядра в режим `powersave`.
3. **Ядра:** Использует интерфейс `online` в ядре. Ядро `cpu0` всегда остается включенным для стабильности системы.
4. **Turbo Boost:** Блокирует технологию через `intel_pstate/no_turbo` (для процессоров Intel).

## ⚠️ Важные примечания

- **Частоты в kHz:** Обратите внимание, что значения указываются в килогерцах (например, 1 ГГц = 1000000).
- **Сброс после перезагрузки:** Все изменения временные и не сохраняются после перезагрузки.
- **Sudo:** Команды, изменяющие параметры системы, требуют запуска с `sudo`.
