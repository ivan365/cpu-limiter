# CPU Limiter

Простой и эффективный Bash-скрипт для ограничения производительности процессора в Linux. Идеально подходит для старых ноутбуков, нетбуков (например, на базе Intel Atom) или серверов, где критически важно снизить тепловыделение и энергопотребление.

## 🚀 Возможности

- **Смена режима (Governor):** Переключает все ядра в режим `powersave`.
- **Ограничение частоты:** Устанавливает максимальную частоту процессора на уровне минимально доступной.
- **Отключение Turbo Boost:** Выключает Intel Turbo Boost для предотвращения скачков температуры.
- **Отключение ядер:** Оставляет активным только первое ядро (`cpu0`), отключая остальные для максимальной экономии энергии.
- **Безопасное восстановление:** Сохраняет текущие настройки перед изменением и позволяет вернуть их одной командой.
- **Автосброс:** Поскольку настройки хранятся в `/tmp`, после перезагрузки система вернется к стандартным параметрам.

## 📋 Требования

- Операционная система Linux.
- Права суперпользователя (`sudo`) для изменения параметров ядра и частоты.
- Наличие интерфейса `cpufreq` в `/sys/devices/system/cpu`.

## 🛠 Установка

1. Скачайте скрипт или склонируйте репозиторий.
2. Сделайте файл исполняемым:
   ```bash
   chmod +x cpu-limiter.sh
   ```

## 📖 Использование

Скрипт поддерживает три основные команды:

### 1. Включить ограничение
Максимально ограничивает ресурсы процессора для экономии заряда батареи и охлаждения.
```bash
sudo ./cpu-limiter.sh on
```

### 2. Отключить ограничение
Возвращает настройки процессора (режим и частоты) к тем значениям, которые были до включения скрипта.
```bash
sudo ./cpu-limiter.sh off
```

### 3. Проверить статус
Показывает, активен ли ограничитель в данный момент.
```bash
./cpu-limiter.sh status
```

## 🔍 Как это работает

При выполнении команды `on`, скрипт:
1. Создает резервную копию текущего `governor` и `scaling_max_freq` для каждого ядра в `/tmp/cpu_limit_backup`.
2. Записывает `powersave` в файл управления питанием.
3. Считывает `cpuinfo_min_freq` и устанавливает это значение как максимально допустимое.
4. Если процессор Intel, отключает Turbo Boost через `intel_pstate/no_turbo`.
5. Переводит все ядра, кроме `cpu0`, в режим `offline`.

Команда `off` производит все действия в обратном порядке, используя данные из бэкапа.

## ⚠️ Важные примечания

- **Временный характер:** Все изменения сбрасываются после перезагрузки системы.
- **Производительность:** При включенном ограничении система может работать заметно медленнее. Используйте это для офисной работы, чтения или фоновых задач, не требующих высокой вычислительной мощности.
- **Sudo:** Команды `on` и `off` требуют `sudo`, так как запись в файлы в директории `/sys` разрешена только администратору.
